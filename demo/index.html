Quadratic Functions — a course module preview

math-exercise · live demo

Factoring & Solving Quadratics

A short, self-checking course module built entirely with Quarto and the math-exercise extension — no server, no LMS, just a browser. This page shows one coherent teaching sequence end to end: exercise → hint → worked solution → follow-up → assessment.

🧮 SymPy-checked answers 🌐 Runs fully client-side (Pyodide) 💬 Progressive AI hints 🔁 Randomized task pools

This module targets a first bridging-course topic: factoring and solving quadratic equations via the difference-of-squares pattern and general trinomials. Every exercise below is a live, working math-exercise block — try it.

TipLearning objectives

By the end of this module, a student can:

  • expand and factor simple quadratic expressions,
  • solve a quadratic equation by factoring,
  • apply a quadratic model to a numeric question, and
  • recognize the same pattern across problems of increasing difficulty.

2 · Stuck? Ask for a hint

2 ✓ math-exercise capability: built-in progressive AI feedback

Every exercise on this page already has a Feedback button (next to Check, above). It calls any OpenAI-compatible model — Cerebras, OpenRouter, OpenAI, a local Ollama — configured once per browser, and the hint gets more concrete each time the same student asks again on the same task:

Attempt What the tutor says
1st click A gentle nudge — the solution is not given away
2nd click A concrete hint about the solution approach
3rd+ click The full step-by-step solution
Note

For a live demonstration, click Feedback on the exercise in §1 after entering a (possibly wrong) answer. This needs an API key for the chosen provider — several offer a free tier (see the README). Screenshots of this dialog and the resulting hint bubble are good candidates for the funding application.

3 · The worked solution

3 🧩 demo presentation — standard Quarto callout, not an extension feature

Instead of (or alongside) AI feedback, a course can simply publish the worked solution as ordinary Quarto content — here as a collapsible callout, directly below the matching exercise:

Now go the other way — factor it
Factor the expression: $x^2 - 9 = $
Note📖 Show worked solution

\(x^2 - 9\) is a difference of two squares: \(a^2 - b^2 = (a-b)(a+b)\).

Here \(a = x\) and \(b = 3\), since \(9 = 3^2\). Substituting:

\[x^2 - 9 = x^2 - 3^2 = (x-3)(x+3)\]

Notice this is exactly the reverse of the expansion in the warm-up exercise — the two tasks are the same identity, read in opposite directions.

Two different ideas about “variants,” shown side by side and kept deliberately distinct.

math-exercise already supports a task pool: a set of hand-authored variants of the same problem, one shown at random per browser session, with a reload button (top-right of the box) to draw a new one.

5b · Difficulty progression — an illustration, not a feature

🔮 future vision — hand-written here to stand in for AI generation

The three tasks below are written by hand for this demo. They illustrate what an AI question-generation step could plausibly hand a course author — several variants of the same underlying concept at increasing difficulty — which the author would then drop into math-exercise blocks exactly like any other exercise. math-exercise itself does not generate exercises; it only renders and checks whatever content it is given.

6 · Assessment & progress

6 ✓ per-exercise: strict, symbolic correctness checking 🧩 dashboard below: demo-only illustration

Assessment already happens inside every exercise above: each Check click runs a real symbolic comparison in SymPy, not string matching — it can require a specific algebraic form (factored, expanded, exact, reduced), not just a numerically correct value. That is what makes form: factored above reject a mathematically-correct-but-unfactored answer.

What math-exercise does not currently provide is a course-wide view across many exercises. The panel below is a small demo-only script (assets/progress-tracker.js, ships only with this demo) that watches the pass/fail state math-exercise already puts on the page and aggregates it — illustrating what a lightweight course dashboard or gradebook feed could look like.
