# Teach with interactive diagrams

Let students move a point, draw a curve or build a graph, then discuss why their
construction meets the task. These JSXGraph activities work alongside the
mathematics questions in this project.

[Try graphical activities](https://erasmus-ctm.github.io/math-exercise/graphics-examples.html) ·
[Start authoring](../../docs/authoring.md) · [Technical integration guide](../../docs/jsxgraph-integration.md)

This extension is a focused fork of [jsxgraph/jsxgraph-quarto](https://github.com/jsxgraph/jsxgraph-quarto)
and retains its MIT license.
