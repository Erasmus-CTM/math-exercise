Dynamic matrix input

Your answers are saved only in this browser.

A dynamic matrix lets the student decide how many rows or columns the answer needs. This is useful when finding the size is part of the mathematics—for example, when the dimension of a subspace is not given in advance.

TipEntering answers

Type answers in the empty fields, then select Check. Use * for multiplication, ^ for powers, and parentheses to make grouping clear. Common forms include sqrt(2), sin(x), exp(x), and pi. Enter an exact value unless the question asks for a decimal approximation. Algebraically equivalent expressions are normally accepted; when a particular form is required, the question says so. Input help shows the full notation reference.

TipChanging the matrix size

Use the − and + buttons beside Rows or Columns before or while entering the matrix. Only dimensions that the exercise allows you to change are shown. Fill every visible cell, then select Check.

In exercises that assess complete vectors, all cells in a row or column receive the same color. Green vectors are valid and form an independent family. Yellow vectors belong to the required space, but the yellow family is linearly dependent; no one vector is singled out as “the redundant one.” A red vector is zero or outside the required space. The whole answer is correct only when the submitted vectors form a complete basis.

NoteFor exercise authors

Write a resizable input as, for example, mat{name=Z, rows=3, cols=auto, initial-cols=1, min-cols=0, max-cols=3}. Dynamic matrices use mode: custom. The checker receives the SymPy matrix at response["inputs"][name]["matrix"] and can return whole-vector assessment as {"assessment": {"Z": {"columns": [...]}}} or {"assessment": {"R": {"rows": [...]}}}.

For basis problems, prefer the shared assess_basis(...) helper. The checker only supplies the submitted matrix, whether vectors are stored as rows or columns, the target dimension, and a test for membership in the target space. The helper calculates rank, permutation-invariant partial credit, colors, and standard feedback. Its internal score is available for assessment but hidden from the student, because displaying it could reveal the unknown dimension.

return assess_basis(
    matrix,
    axis="columns",          # or "rows"
    target_dimension=d,
    belongs=lambda vector: all(value.is_number is True and value.is_real is True and value.is_finite is True for value in vector)
        and ...,  # True exactly for vectors in the target space
    name="B",                # the name used in mat{name=B, ...}
    space_name="target space",
)

The helper rejects zero vectors itself, so belongs only needs to test membership. It returns the exercise score, qualitative feedback, and complete row or column assessment. Green means valid and independent, yellow means valid but part of a dependent submitted family, and red means zero or outside the target space. See the README for the complete API contract and scoring formula.

Bases with an unknown number of vectors

The number of basis vectors is the dimension of the subspace, so the student must determine both the entries and the number of vectors. These vector spaces are over \(\mathbb{R}\); enter finite real coordinates.

To check a proposed basis:

  1. Verify that every vector belongs to the required subspace.
  2. Verify that the vectors are linearly independent. Dependence is a property of the entire family, not of whichever vector happens to appear last.
  3. Verify that the independent family spans the entire subspace.

def test(check, symbols):
    def score(B):
        return check({"inputs": {"Z": {"matrix": B}}}, symbols)["score"]
    B = Matrix([[-2, -3], [1, 0], [0, 1]])
    assert score(B) == 1
    assert score(B[:, ::-1]) == 1
    incomplete = B[:, :1]
    assert 0 < score(incomplete) < 1
    dependent = B.row_join(B[:, :1])
    assert score(dependent) < 1
    assert score(zeros(B.rows,B.cols)) == 0
    assert score(I*B) < 1
    assert score(zeros(0,0)) == 0
    # Typed decimals are exact; a typed 0.0 column is still the zero vector.
    decimal = Matrix([[Float("-0.3"), -2], [0, 1], [Float("0.1"), 0]])
    assert score(decimal) == 1
    zero_column = B.row_join(Matrix([Float("0.0")]*3))
    result = check({"inputs": {"Z": {"matrix": zero_column}}}, symbols)
    assert result["assessment"]["Z"]["columns"][-1] == "incorrect"
