Expression answers

Show Quarto exercise source
```{math-exercise}
#| label: variant-triangle
#| mode: numeric
#| decplaces: 3
#| parameters:
#|   ab: [3, 4, 5]
#|   offset: [1, 2]
#| derived:
#|   bc: ab + offset
#|   ratio: bc / sqrt(ab^2 + bc^2)
#| variant-context: 'Right triangle, AB={{ab}} and BC={{bc}}. AC is the hypotenuse.'
#| solution: |
#|   Pythagoras gives $AC=\sqrt{ {{ab}}^2+{{bc}}^2 }$.
#|
#|   Thus $BC/AC={{ratio:.3f}}$ to three decimal places.
#| tests:
#|   - name: exact expression
#|     answers: ['{{bc}}/sqrt({{ab}}^2+{{bc}}^2)']
#|     expected: correct
#|   - name: rounded answer
#|     answers: ['{{ratio:.3f}}']
#|     expected: correct
#|   - name: reversed ratio
#|     answers: ['sqrt({{ab}}^2+{{bc}}^2)/{{bc}}']
#|     expected: wrong

A right triangle has legs $AB={{ab}}$ and $BC={{bc}}$.
Find $BC/AC$, to **three decimals**: _[{{bc}}/sqrt({{ab}}^2+{{bc}}^2)].
```

Perpendicular vectors

Show Quarto exercise source
```{math-exercise}
#| label: variant-perpendicular
#| mode: custom
#| context: none
#| parameters:
#|   a:
#|   - 2
#|   - 3
#|   b:
#|   - 1
#|   - 4
#| tests:
#| - name: perpendicular
#|   answers:
#|   - -{{b}}
#|   - '{{a}}'
#|   expected: correct
#| - name: zero vector
#|   answers:
#|   - 0
#|   - 0
#|   expected: wrong
#| - name: parallel
#|   answers:
#|   - '{{a}}'
#|   - '{{b}}'
#|   expected: wrong
#| - name: decimal perpendicular
#|   answers:
#|   - -0.{{b}}
#|   - '0.{{a}}'
#|   expected: correct
#| - name: decimal zero vector
#|   answers:
#|   - '0.0'
#|   - '0.0'
#|   expected: wrong
#| - name: disguised zero vector
#|   answers:
#|   - cos(1)^2+sin(1)^2-1
#|   - 0
#|   expected: wrong
#| - name: complex vector
#|   answers:
#|   - -{{b}}*I
#|   - '{{a}}*I'
#|   expected: wrong
#| - name: symbolic vector
#|   answers:
#|   - -{{b}}*t
#|   - '{{a}}*t'
#|   expected: wrong
#| checker: |
#|   def check(response, symbols):
#|       a = response['variant']['parameters']['a']
#|       b = response['variant']['parameters']['b']
#|       # Typed decimals are exact: 0.1 means 1/10.
#|       exact = lambda value: value.xreplace({f: Rational(str(f)) for f in value.atoms(Float)})
#|       u, v = map(exact, response['expressions'])
#|       real = all(w.is_number is True and w.is_real is True and w.is_finite is True for w in (u, v))
#|       nonzero = real and (simplify(u).is_zero is False or simplify(v).is_zero is False)
#|       return {'correct': nonzero and simplify(a*u+b*v).is_zero is True}

Give a **nonzero** real vector perpendicular to $({{a}},{{b}})$: _[0], _[0].
```

Matrix relations

Show Quarto exercise source
```{math-exercise}
#| label: variant-matrix
#| mode: custom
#| context: none
#| parameters:
#|   a:
#|   - 2
#|   - 3
#| tests:
#| - response:
#|     kind: expressions
#|     raw: []
#|     inputs:
#|       A:
#|         type: matrix
#|         rows: 2
#|         cols: 2
#|         raw:
#|         - '{{a}}'
#|         - 0
#|         - 0
#|         - -{{a}}
#|   expected: correct
#| - response:
#|     kind: expressions
#|     raw: []
#|     inputs:
#|       A:
#|         type: matrix
#|         rows: 1
#|         cols: 1
#|         raw:
#|         - '{{a}}'
#|   expected: wrong
#| checker: |
#|   def check(response, symbols):
#|       a = response['variant']['parameters']['a']
#|       A = response['inputs']['A']['matrix']
#|       return {'correct': A.shape == (2,2) and simplify(A*A-a*a*eye(2)) == zeros(2)}

Find a $2\times 2$ matrix $A$ with $A^2={{a}}^2 I$: mat{name=A, rows=2, cols=2}.
```

```{math-exercise}
#| label: variant-coupled
#| mode: custom
#| context: none
#| parameters:
#|   total:
#|   - 3
#|   - 5
#| tests:
#| - answers:
#|   - 1
#|   - '{{total}}-1'
#|   expected: correct
#| - answers:
#|   - 0
#|   - '{{total}}'
#|   expected: wrong
#| - answers:
#|   - '{{total}}'
#|   - '{{total}}'
#|   expected: wrong
#| checker: |
#|   def check(response, symbols):
#|       total = response['variant']['parameters']['total']
#|       u,v = response['expressions']
#|       return {'correct': u.is_positive and v.is_positive and simplify(u+v-total)==0}

Give two positive numbers whose sum is ${{total}}$: _[0], _[0].
```

```{math-exercise}
#| label: variant-geometry
#| mode: custom
#| context: none
#| parameters:
#|   radius:
#|   - 1
#|   - 2
#| response: jsxgraph:variant-point
#| tests:
#| - response:
#|     point:
#|       x: '{{radius}}'
#|       y: 0
#|   expected: correct
#| - name: within drawing tolerance
#|   response:
#|     point:
#|       x: '{{radius}}'
#|       y: 0.04
#|   expected: correct
#| - name: visibly off the circle
#|   response:
#|     point:
#|       x: '{{radius}}.1'
#|       y: 0
#|   expected: wrong
#| - response:
#|     point:
#|       x: 0
#|       y: 0
#|   expected: wrong
#| - response:
#|     point:
#|       x: nan
#|       y: 0
#|   expected: wrong
#| checker: |
#|   def check(response, symbols):
#|       import math
#|       radius = response['variant']['parameters']['radius']
#|       x,y = float(response['point']['x']), float(response['point']['y'])
#|       # 0.05 units is four screen pixels on the 480-pixel board: dragging precision.
#|       good = math.isfinite(x) and math.isfinite(y) and abs(math.hypot(x, y) - radius) <= 0.05
#|       return {'correct': good}

Move point $P$ onto the circle $x^2+y^2={{radius}}^2$.
```
