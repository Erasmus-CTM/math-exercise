Open-ended and custom assessment

Your answers are saved only in this browser.

TipEntering answers

Type answers in the empty fields, then select Check. Use * for multiplication, ^ for powers, and parentheses to make grouping clear. Common forms include sqrt(2), sin(x), exp(x), and pi. Enter an exact value unless the question asks for a decimal approximation. Algebraically equivalent expressions are normally accepted; when a particular form is required, the question says so. Input help shows the full notation reference.

These tasks accept a family of valid answers rather than one predetermined expression. A trusted, instructor-authored checker evaluates the complete response and can award partial credit.

For authors, mode: custom provides the checker with the parsed expressions and declared symbols. The collapsed source below each example shows the complete Python/SymPy checker and its feedback rules.

Warning

Checker code is included in the generated HTML and executes in browser-side Pyodide. It must come only from trusted document authors. It is assessment logic, not a secure place for secrets or high-stakes exam answers.

1. Assess a mathematical property

A function is non-decreasing on \([0,1]\) when \(f(x_2)\ge f(x_1)\) whenever \(0\le x_1<x_2\le1\). This exercise accepts any such continuously differentiable real function whose value at 1 is strictly greater than its value at 0; there is no single canonical answer. Examples include x, x^2, and x^3+x.

Any non-decreasing function that rises overall

```{math-exercise}
#| caption: Any non-decreasing function that rises overall
#| vars: x
#| mode: custom
#| checker: |
#|   def check(response, symbols):
#|       from sympy.calculus.util import continuous_domain
#|       f = response["expressions"][0]
#|       x = symbols["x"]
#|       interval = Interval(0, 1)
#|       try:
#|           derivative = diff(f, x)
#|           regular = (f.free_symbols <= {x}
#|                      and f.subs(x, 0).is_real is True
#|                      and continuous_domain(f, x, interval) == interval
#|                      and continuous_domain(derivative, x, interval) == interval)
#|           lower = minimum(derivative, x, interval) if regular else S.NegativeInfinity
#|           rise = simplify(f.subs(x, 1) - f.subs(x, 0))
#|           valid = regular and lower.is_nonnegative is True and rise.is_positive is True
#|       except (NotImplementedError, ValueError, TypeError):
#|           valid = False
#|       return {"correct": valid,
#|               "feedback": "Require a real function with a continuous derivative, non-negative derivative throughout [0,1], and a positive endpoint rise. Use an expression whose domain and derivative sign SymPy can establish."}
```

A polynomial consistent with two proposed roots

\(p(x)=\) , \(r_1=\) , \(r_2=\)
Show Quarto exercise source
```{math-exercise}
#| label: custom-polynomial-roots
#| caption: A polynomial consistent with two proposed roots
#| vars: x
#| mode: custom
#| field-labels: Polynomial, First root, Second root
#| checker: |
#|   def check(response, symbols):
#|       # Compare typed decimals exactly: 2.0 is 2 and 0.5 is 1/2.
#|       exact = lambda value: value.xreplace({f: Rational(str(f)) for f in value.atoms(Float)})
#|       p, r1, r2 = map(exact, response["expressions"])
#|       x = symbols["x"]
#|       try:
#|           polynomial = Poly(p, x)
#|           monic_quadratic = (polynomial.degree() == 2 and polynomial.LC() == 1
#|                              and p.free_symbols <= {x})
#|       except (PolynomialError, TypeError):
#|           monic_quadratic = False
#|       constant_roots = all(r.is_number is True and r.is_finite is True for r in (r1, r2))
#|       distinct = constant_roots and simplify(r1 - r2).is_zero is False
#|       consistent = constant_roots and simplify(p - (x-r1)*(x-r2)) == 0
#|       score = (int(monic_quadratic) + int(distinct) + int(consistent)) / 3
#|       return {"score": score,
#|               "feedback": "Use two distinct finite constant roots and a monic quadratic equal to (x-r₁)(x-r₂)."}
#| tests: |
#|   def test(check, symbols):
#|       x = symbols["x"]
#|       for values in ((x**2-3*x+2,1,2), (x**2+1,I,-I)):
```

4. Validate a numerical process

To approximate \(\sqrt2\), apply Newton’s method to \(f(x)=x^2-2\). Its update formula simplifies to \[ x_{n+1}=x_n-\frac{x_n^2-2}{2x_n} =\frac12\left(x_n+\frac{2}{x_n}\right). \] This square-root iteration is also known as the Babylonian method. Choose any positive starting value other than the exact root, then apply the displayed formula twice. For example, you may begin with \(x_0=1\).

Two consistent iterations toward sqrt(2)
Choose a positive \(x_0\ne\sqrt2\) and apply
\(x_{n+1}=(x_n+2/x_n)/2\) twice. Give exact values, such as fractions, or decimals
with at least ten significant digits:
\(x_0=\) , \(x_1=\) , \(x_2=\)

```{math-exercise}
#| caption: Two consistent iterations toward sqrt(2)
#| mode: custom
#| field-labels: x₀, x₁, x₂
#| checker: |
#|   def check(response, symbols):
#|       # A typed decimal is the exact number it denotes: 1.5 is 3/2.
#|       exact = lambda value: value.xreplace({f: Rational(str(f)) for f in value.atoms(Float)})
#|       x0, x1, x2 = map(exact, response["expressions"])
#|       if not all(v.is_number is True and v.is_real is True and v.is_finite is True for v in (x0, x1, x2)):
#|           return {"score": 0, "feedback": "Enter finite real numbers for all three iterates."}
#|       step = lambda value: (value + 2/value) / 2
#|       def agrees(value, target):
#|           # Exact values, or decimals correct to about ten significant digits.
#|           difference = simplify(value - target)
#|           return difference == 0 or abs(float(difference)) <= 1e-9 * max(1.0, abs(float(target)))
```

```{math-exercise}
#| label: custom-special-linear-matrix
#| caption: A non-identity integer matrix with determinant 1
#| mode: custom
#| checker: |
#|   def check(response, symbols):
#|       # A typed decimal is the exact number it denotes: 1.0 is the integer 1.
#|       exact = lambda value: value.xreplace({f: Rational(str(f)) for f in value.atoms(Float)})
#|       values = list(map(exact, response["expressions"]))
#|       A = Matrix(2, 2, values)
#|       integer_entries = all(value.is_integer is True for value in values)
```
