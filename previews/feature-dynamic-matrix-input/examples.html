math-exercise – Overview of All Check Modes

This page briefly introduces and lets you try out every check mode of the math-exercise extension. See the README for full option details.

mode: equivalent (default)

Accepts any mathematically equivalent representation.

equivalent
Compute the area of a circle with r = 3 cm.
A = cm²
Show source 
```{math-exercise}
#| label: ex-equivalent
#| caption: equivalent
Compute the area of a circle with r = 3 cm.
A = _[pi * 9] cm²
```

Try pi*9, 9*pi, and 3**2*pi – all are accepted.

mode: exact

The strictest check mode: accepts only the canonical SymPy representation.

exact (numeric fraction)
Give 6/8 fully reduced:
Show source 
```{math-exercise}
#| label: ex-exact-numeric
#| caption: exact (numeric fraction)
#| mode: exact
Give 6/8 fully reduced: _[3/4]
```

3/4 is accepted. 6/8 is rejected – even though SymPy reduces 6/8 and 3/4 to the same internal object on parse, mode: exact additionally checks the raw text you typed for un-reduced numeric fractions (including ones hidden inside expressions like 1/4 + 2/4).

exact (algebraic)
Give the factored form of x² + 2x + 1:
Show source 
```{math-exercise}
#| label: ex-exact
#| caption: exact (algebraic)
#| vars: x
#| mode: exact
Give the factored form of x² + 2x + 1: __[(x+1)**2]
```

(x+1)**2 is accepted. x**2+2*x+1 is mathematically equivalent but a different representation, so it’s rejected as “correct, but not in the requested form”.

reject (add-on for equivalent)

Rejects one specific – mathematically equivalent – expression. Useful for simplification tasks.

equivalent + reject
Simplify (x+1)²:
Show source 
```{math-exercise}
#| label: ex-reject
#| caption: equivalent + reject
#| vars: x
#| mode: equivalent
#| reject: (x+1)**2
Simplify (x+1)²: __[x**2 + 2*x + 1]
```

(x+1)^2 and (1+x)^2 are rejected; x^2 + 2x + 1 is accepted.

mode: numeric – tolerance

Compares numeric values instead of expressions, with an absolute or relative (%) tolerance.

numeric + tolerance
Approximate π (2 decimal places):
Show source

```{math-exercise}
#| tolerance: 0.01

```

3.14 is accepted; 3.10 is not (deviation > 0.01).

mode: string

Literal text comparison, no SymPy parsing. Useful for terms rather than expressions.

string
What is the name of Euler's number in SymPy notation (exact case)?

```{math-exercise}
#| caption: string

```

Only E is accepted – e or Euler is not.

mode: set

Comma-separated list, order doesn’t matter, each element is checked individually like equivalent. Useful for “list all solutions” tasks.

set
Solve x² = 4. All solutions (comma-separated):
Show source 
```{math-exercise}
#| label: ex-set
#| caption: set
#| vars: x
#| mode: set
Solve x² = 4. All solutions (comma-separated): __[2, -2]
```

-2, 2, 2,-2, and sqrt(4), -2 are all accepted; a missing or duplicate solution is rejected.

Partial credit for a set

With partial credit enabled, correctly matched items earn credit while missing items and extra guesses both lower the score.

set with partial credit
List all integer solutions of $(x-1)(x-2)(x-3)(x-4)=0$:
Show source 
```{math-exercise}

#| caption: set with partial credit
#| vars: x
#| mode: set
#| partial-credit: true
List all integer solutions of $(x-1)(x-2)(x-3)(x-4)=0$: ___[1, 2, 3, 4]
```

Try 1, 2, then 1, 2, 5, and finally all four solutions.

mode: custom — monotone increasing with flat points allowed

This checker receives the student’s parsed SymPy expression and verifies that its derivative is non-negative on \([0,1]\) and that the function rises overall.

custom SymPy checker
Give an example of a monotonically increasing function on $[0,1]$:

$f(x) =$
Show source 
```{math-exercise}
#| label: ex-custom-monotonicity
#| caption: custom SymPy checker
#| vars: x
#| mode: custom
#| checker: |
#|   def check(response, symbols):
#|       f = response["expressions"][0]
#|       x = symbols["x"]
#|       lower = minimum(diff(f, x), x, Interval(0, 1))
#|       rise = simplify(f.subs(x, 1) - f.subs(x, 0))
#|       if lower.is_nonnegative is True and rise.is_positive is True:
#|           return {
#|               "score": 1.0,
#|               "feedback": "The derivative is non-negative and the function rises overall."
#|           }
#|       return {
#|           "score": 0.0,
#|           "feedback": "Non-decreasing behavior with an overall rise was not established."
#|       }

Give an example of a monotonically increasing function on $[0,1]$:

$f(x) =$ ___[]
```

Try x, x**2 + x, and x**2. All three are accepted; isolated zero derivatives and flat portions are allowed, provided the function never decreases and rises overall.

JSXGraph response — movable piecewise-linear function

Move the points vertically. Full credit allows flat segments, but requires no decreasing segment and a genuine overall rise. The JSXGraph iframe sends its point coordinates as arbitrary JSON when Check or Feedback is clicked.

```{.jsxgraph assessment_id="pwl-monotonicity-board" width="800" height="420" style="border:1px solid #ddd; border-radius:8px; max-width:100%;"}
        decreasingSegments: slopes.filter(function (s) { return s < -1e-8; }).length,
```

JSXGraph response — freehand drawing and polynomial approximation

Draw a curve across \([0,1]\). JSXGraph bins the captured pointer samples, fits a degree-five regression polynomial, and displays the approximation. Assessment uses dense samples of the fitted polynomial rather than the original noisy stroke.

Show JSXGraph source 
```{.jsxgraph assessment_id="freehand-monotonicity-board" width="800" height="440" style="border:1px solid #ddd; border-radius:8px; max-width:100%;"}
var board = JXG.JSXGraph.initBoard(BOARDID, {
  boundingbox: [-0.1, 1.25, 1.1, -0.25],
  axis: true,
  pan: { enabled: false },
  zoom: { enabled: false },
  showNavigation: false
});

var drawing = false;
var sketch = null;
var fittedGraph = null;
var rawSamples = [];
var regression = null;
var regressionDegree = 5;

function binnedSamples(samples, count) {
  var bins = Array.from({ length: count }, function () { return []; });
  samples.forEach(function (point) {
    if (point[0] < 0 || point[0] > 1 || !Number.isFinite(point[1])) return;
    var index = Math.max(0, Math.min(count - 1, Math.round(point[0] * (count - 1))));
    bins[index].push(point[1]);
  });
  return bins.map(function (values, index) {
    if (!values.length) return null;
    var mean = values.reduce(function (sum, value) { return sum + value; }, 0) / values.length;
    return [index / (count - 1), mean];
  }).filter(Boolean);
}

function fitSketch() {
  var samples = binnedSamples(rawSamples, 51);
  regression = null;
  if (fittedGraph) board.removeObject(fittedGraph);
  fittedGraph = null;
  if (samples.length < regressionDegree + 1) return;

  var dataX = samples.map(function (point) { return point[0]; });
  var dataY = samples.map(function (point) { return point[1]; });
  regression = JXG.Math.Numerics.regressionPolynomial(regressionDegree, dataX, dataY);
  fittedGraph = board.create('functiongraph', [regression, 0, 1], {
    strokeColor: '#dc2626',
    strokeWidth: 4,
    fixed: true
  });
  board.update();
}

board.on('down', function (event) {
  if (drawing) return;
  drawing = true;
  rawSamples = [];
  regression = null;
  if (sketch) board.removeObject(sketch);
  if (fittedGraph) board.removeObject(fittedGraph);
  fittedGraph = null;
  sketch = board.create('curve', [[], []], {
    strokeColor: '#94a3b8',
    strokeWidth: 7,
    lineCap: 'round',
    fixed: true
  });
  if (event.pointerId !== undefined && board.containerObj.setPointerCapture) {
    board.containerObj.setPointerCapture(event.pointerId);
  }
});

board.on('move', function (event) {
  if (!drawing) return;
  var screen = board.getMousePosition(event);
  var coords = new JXG.Coords(JXG.COORDS_BY_SCREEN, screen, board);
  var point = [coords.usrCoords[1], coords.usrCoords[2]];
  rawSamples.push(point);
  sketch.dataX.push(point[0]);
  sketch.dataY.push(point[1]);
  board.update();
});

function finishSketch(event) {
  if (!drawing) {
    board.mode = board.BOARD_MODE_NONE;
    return;
  }
  drawing = false;
  board.mode = board.BOARD_MODE_NONE;
  if (event && event.pointerId !== undefined && board.containerObj.hasPointerCapture &&
      board.containerObj.hasPointerCapture(event.pointerId)) {
    board.containerObj.releasePointerCapture(event.pointerId);
  }
  fitSketch();
}

board.on('up', finishSketch);
board.containerObj.addEventListener('pointercancel', finishSketch);
board.containerObj.addEventListener('lostpointercapture', finishSketch);
window.addEventListener('blur', finishSketch);

function responseData() {
  var inside = rawSamples.filter(function (point) { return point[0] >= 0 && point[0] <= 1; });
  var xs = inside.map(function (point) { return point[0]; });
  var coverage = xs.length ? Math.max.apply(null, xs) - Math.min.apply(null, xs) : 0;
  var fitSamples = [];
  if (regression) {
    for (var i = 0; i <= 200; i++) {
      var x = i / 200;
      fitSamples.push([x, regression(x)]);
    }
  }
  return {
    representation: 'freehand-polynomial-regression',
    interval: [0, 1],
    rawSamples: rawSamples,
    coverage: coverage,
    regression: regression ? {
      degree: regressionDegree,
      term: regression.getTerm ? regression.getTerm() : '',
      samples: fitSamples
    } : null
  };
}

JXG.QuartoAssessment.register({
  board: board,
  response: responseData,
  ai: {
    render: true,
    summary: function (data) {
      var samples = data.regression ? data.regression.samples : [];
      var slopes = samples.slice(1).map(function (point, i) {
        return (point[1] - samples[i][1]) / (point[0] - samples[i][0]);
      });
      var decreasingIntervals = [];
      var decreasingStart = null;
      slopes.forEach(function (slope, i) {
        if (slope < -1e-3 && decreasingStart === null) decreasingStart = samples[i][0];
        if (slope >= -1e-3 && decreasingStart !== null) {
          decreasingIntervals.push([decreasingStart, samples[i][0]]);
          decreasingStart = null;
        }
      });
      if (decreasingStart !== null && samples.length) {
        decreasingIntervals.push([decreasingStart, samples[samples.length - 1][0]]);
      }
      return {
        representation: data.representation,
        interval: data.interval,
        rawSampleCount: data.rawSamples.length,
        domainCoverage: data.coverage,
        polynomialDegree: data.regression ? data.regression.degree : null,
        minimumSampledSlope: slopes.length ? Math.min.apply(null, slopes) : null,
        nondecreasingSlopeFraction: slopes.length ? slopes.filter(function (slope) { return slope >= -1e-3; }).length / slopes.length : null,
        decreasingIntervals: decreasingIntervals,
        feedbackPolicy: 'Discuss only the visible shape and qualitative behavior. Do not reveal, reconstruct, or display polynomial coefficients, fitted expressions, symbolic derivatives, raw samples, or point coordinates.'
      };
    }
  }
});
```

JSXGraph response — editable freehand polynomial approximation

Draw a curve across \([0,1]\). JSXGraph simplifies the captured pointer samples to nine fixed-x adjustment points and fits a degree-five regression polynomial. After you move one blue point, all blue points are projected back onto the new red polynomial. Assessment uses dense samples of that polynomial.

Show JSXGraph source 
```{.jsxgraph assessment_id="editable-freehand-monotonicity-board" width="800" height="440" style="border:1px solid #ddd; border-radius:8px; max-width:100%;"}
var board = JXG.JSXGraph.initBoard(BOARDID, {
  boundingbox: [-0.1, 1.25, 1.1, -0.25],
  axis: true,
  pan: { enabled: false },
  zoom: { enabled: false },
  showNavigation: false
});

var drawing = false;
var sketch = null;
var fittedGraph = null;
var rawSamples = [];
var controlPoints = [];
var controlGuides = [];
var regression = null;
var regressionDegree = 5;
var controlPointCount = 9;

function binnedSamples(samples, count) {
  var bins = Array.from({ length: count }, function () { return []; });
  samples.forEach(function (point) {
    if (point[0] < 0 || point[0] > 1 || !Number.isFinite(point[1])) return;
    var index = Math.max(0, Math.min(count - 1, Math.round(point[0] * (count - 1))));
    bins[index].push(point[1]);
  });
  return bins.map(function (values, index) {
    if (!values.length) return null;
    var mean = values.reduce(function (sum, value) { return sum + value; }, 0) / values.length;
    return [index / (count - 1), mean];
  }).filter(Boolean);
}

function removeControlPoints() {
  controlPoints.forEach(function (point) { board.removeObject(point); });
  controlGuides.forEach(function (guide) { board.removeObject(guide); });
  controlPoints = [];
  controlGuides = [];
}

function updateInterpolation(activePoint) {
  regression = null;
  if (controlPoints.length < regressionDegree + 1) return;
  var dataX = controlPoints.map(function (point) { return point.X(); });
  var dataY = controlPoints.map(function (point) { return point.Y(); });
  var fitted = JXG.Math.Numerics.regressionPolynomial(regressionDegree, dataX, dataY);
  var offset = activePoint ? activePoint.Y() - fitted(activePoint.X()) : 0;

  controlPoints.forEach(function (point, index) {
    if (point !== activePoint) {
      point.setPosition(JXG.COORDS_BY_USER, [dataX[index], fitted(dataX[index]) + offset]);
    }
  });
  var projectedY = controlPoints.map(function (point) { return point.Y(); });
  regression = JXG.Math.Numerics.regressionPolynomial(regressionDegree, dataX, projectedY);

  if (!fittedGraph) {
    fittedGraph = board.create('functiongraph', [function (x) {
      return regression ? regression(x) : NaN;
    }, 0, 1], {
      strokeColor: '#dc2626',
      strokeWidth: 4,
      fixed: true
    });
  }
  board.fullUpdate();
}

function createControlPoints() {
  var samples = rawSamples.filter(function (point) {
    return point[0] >= 0 && point[0] <= 1 && Number.isFinite(point[1]);
  });
  if (samples.length < regressionDegree + 1) return;

  var coords = samples.map(function (point) {
    return new JXG.Coords(JXG.COORDS_BY_USER, point, board);
  });
  var simplified = JXG.Math.Numerics.Visvalingam(coords, controlPointCount - 2);
  controlPoints = simplified.map(function (coord) {
    var x = coord.usrCoords[1];
    var guide = board.create('line', [[x, 0], [x, 1]], {
      visible: false,
      fixed: true
    });
    controlGuides.push(guide);
    var point = board.create('glider', [x, coord.usrCoords[2], guide], {
      name: '',
      size: 4,
      strokeColor: '#1d4ed8',
      fillColor: '#60a5fa',
      highlightStrokeColor: '#1e40af',
      highlightFillColor: '#93c5fd'
    });
    point.on('drag', function () { updateInterpolation(point); });
    point.on('up', function () { updateInterpolation(point); });
    return point;
  });

  updateInterpolation();
}

board.on('down', function (event) {
  if (drawing) return;
  var hits = board.getAllObjectsUnderMouse ? board.getAllObjectsUnderMouse(event) : [];
  if (hits.some(function (object) { return object.elType === 'point' || object.elType === 'glider'; })) return;
  drawing = true;
  rawSamples = [];
  regression = null;
  if (sketch) board.removeObject(sketch);
  if (fittedGraph) board.removeObject(fittedGraph);
  fittedGraph = null;
  removeControlPoints();
  sketch = board.create('curve', [[], []], {
    strokeColor: '#94a3b8',
    strokeWidth: 7,
    lineCap: 'round',
    fixed: true
  });
  if (event.pointerId !== undefined && board.containerObj.setPointerCapture) {
    board.containerObj.setPointerCapture(event.pointerId);
  }
});

board.on('move', function (event) {
  if (!drawing) return;
  var screen = board.getMousePosition(event);
  var coords = new JXG.Coords(JXG.COORDS_BY_SCREEN, screen, board);
  var point = [coords.usrCoords[1], coords.usrCoords[2]];
  rawSamples.push(point);
  sketch.dataX.push(point[0]);
  sketch.dataY.push(point[1]);
  board.update();
});

function finishEditableSketch(event) {
  if (!drawing) {
    board.mode = board.BOARD_MODE_NONE;
    return;
  }
  drawing = false;
  board.mode = board.BOARD_MODE_NONE;
  if (event && event.pointerId !== undefined && board.containerObj.hasPointerCapture &&
      board.containerObj.hasPointerCapture(event.pointerId)) {
    board.containerObj.releasePointerCapture(event.pointerId);
  }
  createControlPoints();
}

board.on('up', finishEditableSketch);
board.containerObj.addEventListener('pointercancel', finishEditableSketch);
board.containerObj.addEventListener('lostpointercapture', finishEditableSketch);
```

Mini-machine number representation

The mini-machine uses the simplified floating-point format

\[ \boxed{S}\quad\boxed{EEE}\quad\boxed{MMMM}, \]

where:

  • \(S\) is one sign bit;
  • \(E\) is a three-bit exponent field;
  • \(M\) is a four-bit mantissa field;
  • the exponent bias is \(3\).

Only normalized numbers with \(E=1,2,\ldots,6\) are used. The bit patterns \(E=0\) and \(E=7\) are excluded, so this mini-machine ignores subnormal numbers, infinities, and NaNs.

A bit pattern represents the number

\[ (-1)^S\left(1+\frac{M}{16}\right)2^{E-3}, \]

where \(M\) is the integer value of the four mantissa bits.

For example,

\[ 0\;|\;100\;|\;0110 \]

has \(S=0\), \(E=(100)_2=4\), \(e=4-3=1\), and \(M=(0110)_2=6\). Therefore,

\[ x=(1+6/16)2^1=2.75. \]

To encode a representable number, first write it as

\[ \pm(1.MMMM)_2\,2^e. \]

Then determine the sign bit, calculate the stored exponent \(E=e+3\), and write \(S\), \(E\), and \(M\) as bit fields.
