Open-ended and custom assessment

TipEntering answers

Type answers in the empty fields, then select Check. Use * for multiplication, ^ for powers, and parentheses to make grouping clear. Common forms include sqrt(2), sin(x), exp(x), and pi. Enter an exact value unless the question asks for a decimal approximation. Algebraically equivalent expressions are normally accepted; when a particular form is required, the question says so. Input help shows the full notation reference.

These tasks accept a family of valid answers rather than one predetermined expression. A trusted, instructor-authored checker evaluates the complete response and can award partial credit.

For authors, mode: custom provides the checker with the parsed expressions and declared symbols. The collapsed source below each example shows the complete Python/SymPy checker and its feedback rules.

Warning

Checker code is included in the generated HTML and executes in browser-side Pyodide. It must come only from trusted document authors. It is assessment logic, not a secure place for secrets or high-stakes exam answers.

4. Validate a numerical process

To approximate \(\sqrt2\), apply Newton’s method to \(f(x)=x^2-2\). Its update formula simplifies to \[ x_{n+1}=x_n-\frac{x_n^2-2}{2x_n} =\frac12\left(x_n+\frac{2}{x_n}\right). \] This square-root iteration is also known as the Babylonian method. Choose any positive starting value other than the exact root, then apply the displayed formula twice. For example, you may begin with \(x_0=1\).

Choose a positive \(x_0\ne\sqrt2\) and apply
