Graph theory constructions

These exercises use the shared JXG.QuartoGraphEditor API. Click Show controls on any canvas for a reminder of the interactions. Every graph is converted from the editor’s JSON response into a validated NetworkX graph by the shared graph_from_response(...) checker helper. See the graph-editor API reference for authoring details.

Construct a tree

Construct a tree with at least five vertices.

Show JSXGraph source and policy YAML
```{.jsxgraph assessment_id="tree-construction-board" width="800" height="520" style="border:1px solid #ddd; border-radius:8px; max-width:100%;"}
var editor = JXG.QuartoGraphEditor.createBoard();
editor.register({
  ai: {
    render: true,
    summary: function (data) {
      return JXG.QuartoGraphEditor.summarize(data, {
        feedbackPolicy: 'Discuss connectedness and cycles without proposing a finished graph.'
      });
    }
  }
});
```
